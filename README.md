# TV Series Hub

This is a website with TV shows categorized by their respective networks.

## General Info

You can search, filter and add shows to your watchlist and then receive alerts about new episodes, series and seasons finale. The stack used consists of Vue 3, Koa, Supertokens and the API by TV Maze. Note that any and all alerts are fully depended on the manner and timing of TV Maze's updates.
